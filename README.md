# [FTP (For the People)](https://silxer12.github.io/FTP/)
An expanding collection of static web tools made "For The People"

If you have any suggestions to make any of these tools better to use or look at, please open an issue with an enhancement label [here](https://github.com/Silxer12/FTP/issues).
Any feedback related to the website or even the code greatly helps.

This project is directly from my hatred of "free" and "no sign up" websites that: steal data, require sign up, push ads into your face, and are all around annoying to use.

## FTP Guide
1. Never display ads
2. Never use cookies
3. Never ask to sign in
4. Never require payment
5. Always keep data local
6. Features over fashion
