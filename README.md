# [FTP (For the People)](https://silxer12.github.io/FTP/)
An expanding collection of static web tools made "For The People"

This project is directly from my hatred of "free" and "no sign up" websites that: steal data, require sign up, push ads into your face, and are all around annoying to use.

If you have any suggestions to make any of these tools better to use or look at, please open an issue [here](https://github.com/Silxer12/FTP/issues).

FTP will always follow these rules:
1. Never display ads
2. Never use cookies
3. Never ask to sign in
4. Never require payment (i.e. a pro tier for extra benefits)
5. Never collect data on users
6. Never vibecode anything
7. Always prioritize user experience over looks (unless looks drastically affects user experience)
