# FTP
Collection of static web tools made "For The People"

You can find the tool hub website [here](https://silxer12.github.io/FTP/)

This project is directly from my hatred of "free" and "no sign up" websites that: steal data, require sign up, push ads into your face, and are all around annoying to use.
If you have any suggestions to make any of these tools better to use or look at, please open a issue [here](https://github.com/Silxer12/FTP/issues).
